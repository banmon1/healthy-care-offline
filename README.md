# Healthy Care

An offline Arabic exercise and activity app. This is the corresponding source for Android package `com.healthy.securehealth`, version 2.0.1 (code 3). The library, muscle explorer, water log, favourites and training progress work on the device. Additional training and meal schedules use a Google Play monthly subscription.

## Build

Use Node.js 22, JDK 17 and Android SDK 36 with the NDK and CMake versions selected by Expo SDK 54. Install dependencies using `npm ci`, then generate the Android project with `npx expo prebuild --platform android`. Set `ANDROID_HOME` to the SDK installation. From the generated `android` folder run `gradlew.bat :app:bundleRelease` on Windows or `./gradlew :app:bundleRelease` on macOS/Linux. The release bundle is unsigned. Use your own signing credentials for distribution. For a development device, use `npm run android` from the project root.

Run `npx tsc --noEmit` to check TypeScript. With a Node runtime that supports TypeScript type stripping, run `node --test scripts/nabilo-step-counter.test.mjs` for the step delta and rollover cases. The native sensor and Google Play Billing require a compatible device. The Play product identifier is `healthy_care_pro_monthly` with base plan `monthly`.
